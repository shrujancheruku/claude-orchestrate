# Contributing to orchestrate

Bug reports and feature requests are welcome. Open an issue and describe what happened or what you need. Reproduction steps, the plugin version and the output of the failing command help most.

Pull requests from outside the maintainer, including pull requests from forks, are closed unmerged. Code changes come from the maintainer's own agent pipeline. Describe the change you want in an issue instead.

Issues labelled `ready-for-agent` are briefs for that pipeline, not open calls for contributions. Their text is the spec the pipeline builds against, so please do not open a pull request for one. If you have a suggestion for one, comment on the issue and the maintainer will decide whether to act on it.
